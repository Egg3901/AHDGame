The suggestions board now works like a forum.

- The board lists suggestions as threads with the author, a one-line preview, votes, replies and status on one row. You can sort by top voted, and the category in a thread's breadcrumb filters the board.
- A suggestion opens as a thread. The original post and every reply sit side by side with the author's portrait, party and state. Replies run oldest first with the reply box at the bottom, and each one has a permanent link.
- You can vote and report from the thread itself. Reports go to the moderators like any other player report, for the suggestion or for a single reply.
- Each thread links to its post in the Discord suggestions channel, and new Discord posts link back to the thread and its report form.
