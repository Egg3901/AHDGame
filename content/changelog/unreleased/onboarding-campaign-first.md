date: 2026-10-14
title: The new-player checklist now leads with campaigning
summary: Every new player is asked to run a Campaign, the checklist reward no longer waits on a vote you cannot cast yet, and step progress is recorded.
tags: [onboarding]
badges: [minor]
areas: [fullstack]
---

Campaigning is now a core step on the "Your first moves" checklist for every new player, whatever they came to do. It is the only action that raises Political Influence, and influence also lifts what every fundraiser brings in. Only a Campaign counts for the step; Run Advertisements builds favorability, which is a different thing.

"Cast your first vote" stays on the list but is marked as a later step. It needs a seat, which a player joining a world that is already running cannot win for days, so it no longer holds back the completion reward.

The game now records when each step was first completed, so we can see where new players get stuck.
