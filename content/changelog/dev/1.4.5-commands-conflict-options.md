Cut from development.

## Fixed

- The Commands tab in the defence office now lists the wars a general can be
  posted to. The tab sat between the briefing and the command builder and did
  not pass the conflict list through, so the dropdown rendered its empty
  placeholder and nothing else. A defence seat could not send a single general
  to a front from this page. The Commanding General page has always sourced the
  same list correctly, which is the only reason postings could be made at all.

- A general already posted to a war is named by that war instead of by its
  internal id. The badge looks the theatre up in the same list, so with the list
  missing it fell through to printing the id, and players saw a chip reading
  something like `war_us_dd_415`. That also made the tab look self contradictory:
  the badge said the general was posted while the dropdown next to it said they
  were not.

- The Combat Command page's doctrine panel had the same stand in, and that one
  was not shadowed by anything: the line under every posted general has been
  showing the conflict's internal id rather than the war's name. The conflicts
  were already on the state the panel is handed, so it now reads the name from
  them.

- Removed a second module level stand in of the same kind in the command detail
  panel. It was shadowed by the real lookup and so never ran, but it would have
  silently restored this bug the day anyone removed the shadow.
