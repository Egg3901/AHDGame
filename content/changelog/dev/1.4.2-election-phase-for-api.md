Cut from development.

## Fixed

- Election detail read through the public API reported every live race as being
  in its general election. A race sitting in its primary was described as a
  general, and nothing distinguished the two.
- The election list read through the public API only carried the raw status,
  which is "active" for the whole run of a race. There was no way to tell a
  primary from a general.
- A finished race is now recognised from its actual close, not from a status
  value the game never writes.
- Candidates read through the public API were one flat list of everyone who had
  ever entered the race. Someone who lost their primary still read as a running
  candidate, so a party looked like it was still running several people against
  each other when only its nominee was left.
- A candidate who left a race and entered it again read as several candidates at
  once. They now read as one candidate who is standing, alongside a record of
  each earlier departure.

## Changed

- Every election read through the public API now carries a phase: upcoming,
  primary, general, ended or cancelled.
- Elections now report when the phase they are in closes, as both a turn number
  and a timestamp. The start time only ever said when the race spawned, which
  is not the deadline anyone is waiting on.
- The primary close, the general close and the race open are all published as
  turn numbers alongside their timestamps, matching what the election screens
  count down to.
- Candidacies that ended are now published separately from the standing ballot,
  each with the time it ended. Nothing is discarded: a withdrawal or a lost
  primary is kept as a matter of record, it simply no longer reads as someone
  who is still running.
