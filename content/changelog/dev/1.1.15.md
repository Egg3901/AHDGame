## What changed

The commodity market page builds its market scope from a server-provided
state-to-country map. That map can reference a country code the client no
longer has a configuration for (a removed or renamed country, or stale seed
data). The code trusted the mapping unconditionally, so a single stale entry
crashed the whole page with an error screen the moment the lookup ran.

The scope builder now validates the mapped country against the client's
country configs before trusting it, falling back to the currently active
country when the mapping is stale, and country name lookups in market labels
and captions guard against a missing config instead of assuming one exists.

No mechanic change: prices, supply, and demand are computed exactly as
before. A data inconsistency now degrades to a sensible default instead of
taking the page down.
