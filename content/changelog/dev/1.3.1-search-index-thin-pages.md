Cut from development.

## Changed

- Every `/news/post/` permalink is now marked noindex. Only advertisements and system
  posts were before. A wire post is a few dozen words written in character, and a few
  hundred of them in the search index read as filler to a crawler, which counts
  against the whole site.
- News permalinks are out of `sitemap.xml`. The `/news` feed itself stays in, so the
  section is still discoverable.
- A wiki page that is still exactly its starter template is served noindex and left
  out of the sitemap. That covers the player biography, party profile and company
  pages that were created and never filled in. The page returns to the index by
  itself the moment its owner saves any content of their own, with no admin step.
- A news post too short to describe itself now gets a generic page description
  instead of having its body copied into the meta tag. One live post had a
  description of a single full stop.

## Notes

- Nothing is deleted or hidden. Every affected page still loads for anyone who has
  the link or reaches it from inside the game.
- `robots.txt` still allows `/news/post/`. A crawler has to fetch a page to see that
  it is noindex, so blocking the path now would strand the URLs already in the index.
  It gets switched to disallow once they have dropped out.
