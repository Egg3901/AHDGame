Cut from development.

## Changed

- `iterationLabel` now carries a display-override table so a specific iteration
  can render under a different name. The current run (`Iteration 4`) maps to
  `1.0`; every other iteration falls through to the existing `Type Number`
  format. This is the single source of truth for iteration names.
- The season-recap and "wrapped" surfaces, which previously formatted
  `iteration.type` and `iteration.number` inline, now route through
  `iterationLabel` so they show the same name as the rest of the app.
