Cut from development. (#1363)

### Fixed

- The savings account migration planner treated any negative balance as a
  reason to refuse, including float residue below half a cent. Legacy interest
  was credited as raw floats, so a long-lived account can sit at a value like
  -0.000000053, which is not a debt and cannot be settled in any currency.
  Dust in either direction is read as zero; a genuine negative still blocks.
