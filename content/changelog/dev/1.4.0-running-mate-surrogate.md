## Added

- Running-mate surrogate actions for presidential tickets. Once the general
  election opens, the running mate gets their own panel on the campaign page:
  campaign in a state, and canvass voters for the ticket. Visiting a state lends
  the ticket a per-turn presence bonus there; canvassing works exactly like the
  nominee's own canvassing, in the state the running mate is campaigning in.
- A shared daily pool bounds how much the running mate can do. Both surrogate
  acts draw from the same small pool, which refills once a day, so the help is
  steady rather than unlimited. Each act spends the running mate's own actions
  and funds; the campaign treasury is untouched.
- The running mate also gets the campaign's owner-level view and can fire a
  rally and invest in fundraising for the ticket. Those share the ticket's
  existing pools, so a running mate and the nominee cooperate rather than each
  getting a separate turn's worth. Every other campaign control stays with the
  candidate and their managers.

## Notes

- Nothing changes for any race already underway. Running mates are only
  selectable in the general election, and the tuning that decides how much a
  surrogate visit is worth ships at its current value, to be adjusted later.
