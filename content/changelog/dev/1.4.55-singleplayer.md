Cut from development.

## Added

- A start screen at `/singleplayer` with the seven era presets, a name field
  and Continue for an existing world. Starting over asks twice.

- An End turn button in the navigation bar, shown only in a singleplayer
  install. It runs the same turn the server runs for everyone in
  multiplayer.

- A launcher (`launch.mjs`) that finds or downloads MongoDB into
  `~/.a-house-divided`, starts it on loopback, starts the game and opens the
  browser. On Windows it pulls the 28 MB server binary out of the 785 MB
  archive without downloading the rest.

- A local art mirror. Map data and images are fetched from the CDN the first
  time a world needs them and served from disk after that.

## Changed

- A singleplayer world is exempt from the "no turn in ten hours, cron must
  be dead" auto-pause. Days between turns is how it is meant to be played.

- Supreme Court portraits now follow the same CDN base as the rest of the
  art instead of a hardcoded host.
