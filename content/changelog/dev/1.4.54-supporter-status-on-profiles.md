Cut from development.

## Fixed

- A lapsed supporter no longer sees their own badge, profile border and
  highlight colour indefinitely. The public profile has always hidden those
  once a pledge expires; the owner's own profile never checked, so the two
  pages described the same player differently. The owner's page now applies the
  same active-status rule.

- A Lakeside subscription is no longer described as a Patreon pledge. The badge
  has always been able to say which system granted the benefits, but nothing
  passed that through, so every supporter was labelled a Patreon patron
  regardless of who they actually paid.
