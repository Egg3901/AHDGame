## Reachable lens on the world map

The map could already colour countries by supply, demand, price and deposits.
All four are world-aggregate or raw-balance views, so none of them answered the
question a player actually asks before building: can I sell here.

Reachable paints each country by its own book, `demand / supply` where demand is
what that country's sellers can reach after imports and exports. Same book the
turn engine settles against, same book the build gates now quote.

### Palette

The job is POLARITY (which side of demand = supply a country sits on), so the
scale is diverging: two hues and a neutral gray midpoint, never a rainbow and
never a hue in the middle.

Poles are the ones `ShortageHeatMap` already ships (#D64545 shortage, #3E7CB1
glut, #8A8F98 neutral) so the two surfaces read as one system. Each arm was
solved for even OKLCH lightness spacing and checked with the dataviz
`validateOrdinal` in BOTH light and dark mode:

- shortage arm `#e68f8f #dd6363 #c44040 #973535`
- glut arm `#8ab0d0 #6294c0 #3d79ad #325f85`

Both pass lightness-monotone, adjacent dL >= 0.06, light-end contrast and
single-hue. The CATEGORICAL validator fails a correct diverging ramp by design
(it spans the lightness band and a gray midpoint sits under the chroma floor),
so it is not the check that applies; `validateOrdinal` per arm is.

One validated mid-tone set serves every theme, matching the existing reasoning
in ShortageHeatMap: the app ships 10+ named data-theme surfaces, so a per-theme
override would mis-fire on the themes it does not name.

### Details

- Steps escalate at 1.15x / 1.5x / 2x / 3x imbalance and the glut arm mirrors
  the reciprocal, so a 2x glut and a 2x shortage sit the same distance from the
  middle. A linear slice would have put nearly every real market in one bucket.
- A country with no book is left unpainted; one with a book but no activity on
  either side is painted "unknown", which is deliberately a different answer
  from "balanced".
- The legend names BOTH poles and the midpoint, because a polarity scale is
  unreadable if the middle is unlabelled. Its swatch is built from the ramp
  itself, so legend and fill cannot drift.
- The mode is hidden, not disabled, when no book is persisted. An always-greyed
  button on an older world is noise.
- Inside a country drilldown the per-state map falls back to demand colouring:
  sales clear nationally, so there is no per-state reachable ratio to invent.

### Not in this change

- Blocked/untraded disclosure on the country stat card. The shortage heat map
  already names excluded supply; the map repeats the ratio but not yet the
  reason.
- Commodity dropdown on the map (the commodity is still the route).
- Bilateral flow arcs from `tradeFlowSnapshots`.
