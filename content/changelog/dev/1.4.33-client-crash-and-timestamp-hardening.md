## Fixed

- Congress bill timelines and the campaign suspension notice printed every
  timestamp in the server's timezone rather than yours, so a vote deadline
  could read hours away from when it actually falls. Both now render through
  the same local-time component the rest of the game uses. The lint rule that
  is supposed to catch this only looked at files carrying an explicit client
  marker, and these two do not carry one despite running entirely in the
  browser, so it had been passing them over.
- The corporation Overview page crashed to a blank card when a company's
  credit data had not loaded or does not exist, instead of showing the
  "Loading credit data" placeholder it already had for the neighbouring case.
- The executive page could return a server error instead of rendering when a
  government's prime-minister record was stored in an unexpected shape. It now
  resolves the prime minister anyway, and shows the page with no prime minister
  rather than failing if the record is genuinely unusable.
- A party activity feed requested with a malformed page size returned an error
  or an empty feed instead of falling back to the default page size.
