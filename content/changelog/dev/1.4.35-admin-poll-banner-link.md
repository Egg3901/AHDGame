## Added

- A poll banner an admin can turn on and off. It lives in the admin panel under
  Support, and it takes three pieces: the sentence players read, the words the
  link is made of, and where the link goes. Something like "Please fill out the
  survey here for feedback about the game:" followed by a "Click Here" that opens
  the form. There is a tone switch too, so a survey that matters more can be set
  to read as urgent rather than routine.

- The banner shows to everyone, signed in or not, and there is no way for a
  player to dismiss it. That is deliberate: it stays up exactly as long as an
  admin leaves it up, and no longer. Switching it off keeps the wording and the
  link on file, so the same survey can go back up without being retyped. The four
  pages that carry no navigation at all, signing in, registering, the banned
  notice and the maintenance page, are left alone.

- The admin panel previews the banner with the same component that renders it to
  players, so what is on screen while you write it is what ships. The preview
  works while the banner is still switched off, which is when you actually need
  it.

- A link that is not an ordinary web address is refused, and the panel says why
  next to the field. Every save is written to the admin log with who made the
  change and what the banner said.
