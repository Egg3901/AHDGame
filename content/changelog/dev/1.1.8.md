Fixes ticket #1091.

## What was confusing

A player watched a nation sit above 60 percent of the Western pole for a day and
never join NATO, and reasonably asked whether joining was automatic or bugged.
Neither. Reaching 60 percent is only the first of several steps, and every step
after it was hidden.

To join a bloc, a non-player nation has to hold at or above the 60 percent join
share for a sustained run of 24 turns. Only then does it file a membership
application, and the bloc's existing members still vote on it. The turn engine
tracks that run in a `joinReadySince` stamp that resets the moment the share dips
back below the gate. Nothing in the game surfaced it. The one screen that could
have shown a live "held 21 of 24 turns" counter showed it only for members
drifting toward the exit, never for a nation climbing toward accession.

## The fix

The Influence tab now reads the same sustain clock the turn engine keeps and
shows it where a player is already looking at a courted nation.

- The nation dossier states the countdown in plain terms: "It has held above the
  60 for 21/24 turns. If it holds, it applies to join in 3 more turns, then the
  members vote it in. Drop it back below the 60 and the clock resets." Once the
  run completes, it says the application is in and the members' vote now decides.
- In "Closest to joining," a nation over the gate now reads "applies in 3" rather
  than a bare "eligible," so the roster answers "when," not just "yes."

## Changes

- `loadOrgInfluence` computes a `joinCountdown` per courted nation from
  `joinReadySince` and the current turn, gated to non-members that are actually
  on the accession path. A player-run nation never auto-applies, so it shows no
  countdown that would never fire.
- `NationDossier` and `NationsInPlay` render the countdown. No mechanic changed:
  this only surfaces state the turn engine was already keeping.
