## What changed

- `GET /api/public/v1/elections?results=true` now returns `seatsEstimate` on
  multi-seat races: a map of candidate ID to projected seat count. Single-seat
  races (e.g. Senate, governor) leave the key absent, so existing clients are
  unchanged.

- Each entry in the opt-in `results.candidates[]` now includes `favorability`
  and `politicalInfluence`, read from the linked character for player
  candidates and from the linked NPP for non-party candidates. Either is `null`
  when there is no linked record.

- The default response (no `results=true`) and the existing single-election
  detail endpoint are untouched.
