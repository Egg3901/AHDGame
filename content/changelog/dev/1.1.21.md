## What changed

The earlier fix guarded the country-level commodity view against a country code
the client has no configuration for, but two sibling lookups kept the unguarded
form. The state-level market caption read the country name directly, and the
exchange-tab builder read the exchange name directly. When the active country
resolved to stale data, either lookup crashed the page with "reading 'name'".

Both now fall back to the raw country code instead of assuming a configuration
exists, so a data inconsistency degrades to a plain label rather than an error
screen. No mechanic change: prices, supply, and demand are computed exactly as
before.
