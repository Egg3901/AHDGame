Cut from development.

## Changed

- Presidential primaries run on a spread-out calendar. The same six voting
  waves, with the same states in each, now sit across the full primary window
  rather than bunching into the final few turns. Early states lead, later
  states follow with real gaps between them, so a result has time to move the
  race before the next wave votes.
- The primary screen's calendar and stagger label follow whichever schedule a
  race actually runs, so what you see matches when states vote.

## Added

- Momentum. When a candidate beats their projected share in a wave, they bank
  momentum that carries into later waves and fades over time if they stop
  over-performing. It rewards a surprise strong start and punishes a fade.

## Notes

- Momentum is measured and recorded but dormant for now: its strength is set to
  zero until it is tuned, so it does not move any votes yet. Turning it on is a
  later, separate change.
- Races already in progress are unaffected. The spread-out calendar and momentum
  apply only to presidential races that start after this ships.
