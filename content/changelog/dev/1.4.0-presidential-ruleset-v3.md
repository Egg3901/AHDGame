Cut from development.

## Added

- A new presidential ruleset version (v3) carrying every switch the rework
  needs: primary calendar spacing, primary momentum cap and decay, the
  convention toggle, suspended-campaign transfer mode and ceiling, endorsement
  organization and credibility, and the running-mate surrogate cap and travel
  weight. Every value is set to today's behavior, so v1, v2, and v3 are
  identical right now.
- New presidential races are stamped v3 at creation. The live races are
  unstamped and keep the rules they opened under, so this changes nothing for
  any election in progress.

## Guarded

- A test pins that all three versions are behaviorally identical, so a switch
  cannot be flipped by accident; each rework piece flips its own switch on
  purpose alongside the code that reads it.
