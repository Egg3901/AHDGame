## Changed

- Verified the vote-to-position pipeline end to end: the congress and regional
  vote commands both call the real policy shift after recording a first
  non-abstaining vote, moving each axis one 0.25 step toward the bill on an Aye
  and away on a Nay, capped at one step per bill, and snapped to the 0.05 grid.
- Added `billVotePolicyShift.test.ts`, which runs the actual shift helper through
  both vote commands and asserts the write to the character document. The
  existing route test mocked the helper out, so no test previously proved a cast
  vote reached the character.
