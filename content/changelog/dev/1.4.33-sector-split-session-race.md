## Fixed

- Confirming a sector split no longer returns an internal server error. The
  route loaded the attacker, the target, the defender and your existing sector
  all at the same time inside one database transaction. A transaction can only
  handle one read at a time, so the four raced to open it, one won, and the
  other three failed and took the whole split down with them.
- Those reads now happen one after another. Nothing about the split itself
  changes: same cost, same odds, same plants.
