Cut from development.

## Added

- A Campaign Managers panel on your campaign page. The candidate (or an admin)
  can search for a character by name and appoint them as a manager, see the
  current managers, and remove them, up to three. A manager's owning player
  can take campaign actions alongside the candidate.
- The campaign detail now returns the full manager list (names) and whether
  the viewer may change managers, so the panel is read-only for anyone who is
  not the candidate.

## Guarded

- Appointing and removing runs through the existing manager command (same
  country enforced, candidate cannot manage their own campaign, three-manager
  cap), so this change is purely the missing interface for a system that was
  already there. Non-candidates cannot appoint or remove.
- Tests cover the manager list resolution and the appoint permission flag.
