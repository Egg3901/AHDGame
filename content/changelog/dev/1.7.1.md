This focused update makes official desktop Singleplayer access available to the moderation team and repairs the release packaging path for Windows and macOS runtimes.

## What landed in this release

2 changes shipped.

### Interface and platform

- **Moderators can use Singleplayer**
  Moderators now receive official desktop Singleplayer access from the server, without needing a supporter tier or a separate manual grant.
- **Singleplayer runtime bundles publish on every desktop platform**
  Singleplayer release packaging now accepts the platform identifiers used by Windows and macOS, so all supported desktop runtime bundles can publish.
