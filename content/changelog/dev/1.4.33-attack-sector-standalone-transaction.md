## Fixed

- Sector splits no longer fail with an internal server error. The split was
  recently moved inside a multi-document transaction to survive a stale
  database session. Production Mongo runs as a standalone instance, which
  cannot start a transaction at all, so every attempt failed before it began
  and players saw an opaque error.
- The deployment is now checked first, and where transactions are unsupported
  the split runs as a plain sequence of writes. Each of those writes already
  refuses to apply if the plant ledger moved underneath it, so a split still
  cannot double-spend or take plants that are no longer there.
- On that path a failed split now refunds the cash and marketing strength it
  charged. Previously a conflict part-way through could take payment without
  moving any plants.
