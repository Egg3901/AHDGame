## What changed

The Deals tab acquisition search returns only player-run private companies,
because an acquisition offer has to be accepted by a human CEO. State-owned and
AI-run firms have no one to accept, so they are excluded. Nothing in the UI said
this: a search that matched an ineligible company (or nothing at all) simply
rendered an empty result box with no message, which read as a broken feature.
Reported in ticket-1095, where the player noted the target had no bonds and held
no shares (the conditions the helper text called out) yet still never appeared.

The search now shows an explicit "No eligible corporations found" line whenever
a query of two or more characters returns nothing, spelling out that only
player-run private companies can be acquisition targets. The helper text above
the form is reworded to state the player-run requirement up front, so the
constraint is visible before a player starts typing.

No mechanic change: the eligible set is exactly what it was. This makes the
existing rule legible instead of silent.
