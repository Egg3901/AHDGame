Cut from development.

## Fixed

- 11 of the 45 test suites that replace the global `fetch` never put it back,
  so the stub survived into whichever file ran next and that file's own mock
  lost. It surfaced as unrelated pull requests failing on a market-finder test
  that passed when run on its own. Stubbed globals are now cleared at the end
  of every test file.
