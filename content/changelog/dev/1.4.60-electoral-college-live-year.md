Cut from development. PR #1466.

## Fixed

- `loadApportionment(db, preset)` was called without the current year from
  the presidential engine (twice), president resolution, the map presidential
  service, election enrichment, the results route and the campaign queries,
  so `resolveApportionmentYear` fell back to the preset start year forever.
  In a 1953 world the 23rd Amendment gate never tripped: the 1964 college ran
  530 votes with no DC. All seven sites now pass `gameState.currentYear`.
- The presidential engine's per-unit snapshots and its state set iterated the
  static modern `ELECTORAL_VOTE_UNITS`; both now use the live, era-gated unit
  list it already loads.
- The proportional fallback in `computeElectoralVotes` and the map
  presidential service divided the modern 538 instead of the live total.
