## Added

- Public API read endpoints scale the per-key rate limit with the key owner's
  active supporter tier: Supporter+ at 1.5x the base allowance (90 req/min) and
  Supporter++ at 3x (180 req/min). Plain Supporter and non-supporters keep the
  base 60 req/min.
- `/api/public/v1/meta` reports the allowance for each tier alongside the base
  read limit, and the OpenAPI description documents the same contract.
- Settings and the API Automation guide state the per-key limits and point
  integrators at the `X-RateLimit-Limit` header for their live allowance.

## Notes

- The multiplier follows the pledge. A lapsed or expired pledge falls back to
  the base allowance, and a tier change takes effect within a minute.
- Server bot tokens are a shared credential, so they keep the flat base
  allowance. Write endpoints (transfers, forex) are unchanged.
- A tier lookup that cannot reach the database serves the base allowance rather
  than failing the request.
