## What changed

- `SupplyAgreement` gains an optional `stateId`. Proposing a state-scoped commodity (freight) requires it; the state must exist and the supplier must have capacity producing that commodity there. Reachable commodities ignore it.
- Every per-corp contract map in the corporation turn (reservations, cleared units, buyer demand, produced, achievable) is keyed by `supplyAgreementScopeKey`: the bare commodity for corporation-wide agreements, `commodity@stateId` for state agreements. Existing corporation-wide behaviour is byte-identical.
- Clearing lands a state reservation only in the named state's book, on that state's sectors, and credits it under its own key in the settlement sink. A corporation-wide reservation on the same book is credited separately.
- Delivery max-flow, pro-rata rebalancing, premium settlement and shortfall damages all group by scope key, so a Texas freight contract is measured against Texas plants and Texas consumption only.
- The legacy kill switch that withholds state-local clearing now fires only for a live freight agreement WITHOUT a `stateId`, and the migration only retires those. State contracts never disable state books.
- The NPP matcher proposes freight per host state to a buyer with starved plants in the same state, activates state-scoped proposals, and serves cancel notice off that state's capacity.
- The list route reports `capacityByState` for state-scoped commodities (per state, with the state name). The agreement form offers freight again with a "Fulfilled from state" picker and shows the state on the card.
