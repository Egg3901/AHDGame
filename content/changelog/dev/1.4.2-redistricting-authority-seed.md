Cut from development.

## Fixed

- Every US state now begins with its redistricting authority set to
  legislature-drawn. The authority law was orphaned from the current
  legislation catalog, so no state ever had it set and all of them fell back to
  a bipartisan commission, which by design can never redraw. The redistricting
  editor was therefore unreachable for everyone: even a governor of a trifecta
  state opening the Redistrict page was told a commission draws the map. States
  with congressional districts now get the authority as an enacted baseline at
  world seed, and a backfill sets it on the existing world.

## Why

- Legislature-drawn is accurate to the era. In the 1953 and 1960 worlds,
  congressional maps were drawn by state legislatures; independent and
  bipartisan commissions for congressional districting did not exist yet. The
  old default handed every state a mechanism that was both anachronistic and
  the one setting that blocked the feature.

## Notes

- The backfill is insert-only. It never overwrites a state that already has an
  authority row, so any later change stands.
- Changing the authority away from legislature-drawn is not yet a passable bill
  (the law still needs porting to the v2 legislation catalog); that is tracked
  separately.
