Cut from development.

## Fixed

- The Command builder listed the twelve postures by name only. The wiki said each
  posture "carries stated trade-offs on the panel", but the effects list that
  backs that claim was never wired to either posture picker, so a player choosing
  between Expeditionary and Rapid Response had nothing to read. The Create
  Command dialog now shows the selected posture's effects live under the picker,
  and the command detail panel shows the current posture's effects to everyone
  who can see the command, not only the defense seat that can change it.
- The three command types (Homeland Defense, Regional, Logistics) had the same
  gap: their bonuses were listed in config but never shown. The type buttons in
  the Create Command dialog now show the selected type's bonuses, and the
  detail panel shows them under the command's role line.
- The commanding general's own command page named the posture and type with no
  explanation either. It now shows the same trade-offs and bonuses, read-only,
  so a general does not have to ask the defense seat what their posture costs.
