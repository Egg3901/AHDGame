title: "Stop local world child processes through the supervisor"
summary: >-
  Adds a desktop control message that closes the local game server and MongoDB
  before the launcher exits, including when startup is cancelled.
tags: [singleplayer, client]
areas: [backend]
badges: [patch]
---

- The packaged supervisor accepts a bounded shutdown command over stdin.
- MongoDB ownership is recorded before waiting for its port so cancelling
  startup can still close the process.
- Repeated starts of the same world no longer depend on killing only the
  supervisor and leaving child processes behind.
