Cut from development.

## Fixed

- Command economies number their state enterprises from a per-country base plus
  the sector's position in the corporation-type list. That base has moved twice.
  A world seeded under an older layout and then re-seeded kept its old
  enterprise numbers, and the seeder matched sectors on the owning enterprise's
  id, so it could never see them. It inserted a second producing record for the
  same region and the same sector type beside the first, which double-counts
  that country's supply, capacity and workforce.
- The seeder now looks up which corporations the country actually owns before it
  writes, moves a producing sector off a superseded enterprise onto the current
  one, and only then upserts. A sector owned by a player-founded or nationalised
  company is never a candidate, so nothing can be moved out from under a player.
- The bare sovereign issuer counts as a superseded owner for this purpose. It is
  a bond-issuing identity and is seeded with no sectors, so producing sectors
  parked on it are left over from before command economies were split into one
  enterprise per sector, and belong on the enterprise instead.

## Not changed

- Enterprises already running on an older number keep it. The number is
  cosmetic, and the corporation id is referenced by financial history, defence
  contracts, supply agreements and union rosters, none of which follow a
  renumbering. Trading real accumulated history for a tidier id is not a good
  deal. New worlds seed the current layout from the start.
