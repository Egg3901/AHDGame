# Changelog

Release notes from **v0.4.0** onward live as per-version posts under `content/changelog/dev/`.

Pre-0.4.0 history is frozen in `content/changelog/legacy/CHANGELOG.md` and rendered at `/changelog/legacy`.

When updating release notes, edit or add `content/changelog/dev/{version}.md` (and `content/changelog/public/{version}.md` for player-facing changes).
